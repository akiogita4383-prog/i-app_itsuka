# 共有帳・いつか帳プラスを動かすための準備

`www/config.js` の `supabaseUrl` が空のあいだ、アプリは個人用の帳だけで動きます（今の TestFlight 版と同じ）。
次の準備が済んだら `config.js` に値を入れて push すると、共有帳とプラスが使えるようになります。

## 1. Supabase（サーバー）

1. https://supabase.com に GitHub でサインインし、「New project」を作る（リージョンは Tokyo）
2. 左の **SQL Editor** → 新しいクエリに `supabase/migrations/0001_init.sql` の中身を全部貼って **Run**
3. **Authentication → Sign In / Providers → Apple** をオンにし、
   **Client IDs** に `com.akioyamamoto.itsuka` を入れて保存（アプリ内のログインだけなので、Secret Key は空でよい）
4. **Project Settings → API** の「Project URL」と「anon public」キーを `www/config.js` に書く
5. Edge Function を3つ置く（Supabase CLI。この Mac のターミナルで）
   ```
   npx supabase login
   npx supabase link --project-ref <プロジェクトID>
   npx supabase functions deploy verify-purchase
   npx supabase functions deploy delete-account
   npx supabase functions deploy app-store-notifications --no-verify-jwt
   ```

## 2. Apple Developer（Identifiers）

- App ID `com.akioyamamoto.itsuka` の Capabilities で **Sign In with Apple** にチェックして保存
  （App Groups はすでに設定済み）

## 3. App Store Connect（いつか帳プラス）

1. アプリ → **サブスクリプション** → グループ「いつか帳プラス」を作る
2. その中に2つ作る
   | 参照名 | 製品ID | 期間 | 価格 |
   |---|---|---|---|
   | 月額 | `itsuka.plus.monthly` | 1か月 | 300円 |
   | 年額 | `itsuka.plus.yearly` | 1年 | 2,000円 |
   それぞれ表示名・説明・審査用スクリーンショット（課金画面）を入れる
3. アプリ → App 情報 → **App Store サーバ通知** に、本番・Sandbox とも
   `https://<プロジェクトID>.supabase.co/functions/v1/app-store-notifications` を登録（バージョン2）
4. 「契約／税金／口座情報」で有料 App 契約を有効にする（サブスクリプションの販売に必須）

## 4. アフィリエイト（任意）

`www/config.js` の `affiliate` に、Amazon アソシエイトのトラッキングID・楽天アフィリエイトID・バリューコマースの sid/pid を入れる。
空のものは付かない。全部空なら設定画面の項目も出ない。

## 5. 招待リンクの受け口

`npm run build:web` → `dist-web/` を GitHub Pages に置く（`join.html`・`privacy.html`・`support.html` を含む）。
置いた場所が `config.js` の `inviteBase` と一致していること。

## 動作確認（TestFlight）

- 2台の iPhone（または家族の端末）で、片方が共有帳をつくって招待 → もう片方が参加申請 → 承認 → 同じメモが見えるか
- TestFlight での購入は Sandbox（実際には請求されない）
